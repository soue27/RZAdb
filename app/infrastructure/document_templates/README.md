# Исходные шаблоны документов

Этот каталог содержит только исходные шаблоны приложения. Сформированные
документы, пользовательские загрузки и резервные копии хранятся отдельно.

## Структура

- `urza/` — исходные формуляры ОТД, уставок, схем и ТО, которые
  используются генерацией и паспортом УРЗА.
- `inspections/` — активный DOCX-шаблон осмотра подстанции.
- `inspections/legacy/` — прежний PDF-шаблон, сохранённый для истории;
  приложение его больше не предлагает.
- `catalog.py` — единая точка определения путей для конфигурации и DI.

## Правила

1. Для каждого исходного документа храните одну каноническую копию здесь.
2. Новые пути добавляйте в `DocumentTemplateCatalog`; не собирайте пути
   к исходникам строками в routes и сервисах.
3. Сформированные DOCX сохраняйте во временные файлы с удалением после
   отправки, а загруженные пользователями документы — через `FileService`
   и `ObjectStorage`.
4. Не помещайте в этот каталог пользовательские файлы или резервные копии.
5. При обновлении шаблона сохраняйте исходную структуру и проверяйте
   ожидаемые маркеры автоматической подстановки.
